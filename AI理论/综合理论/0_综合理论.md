1. 大模型像一本百科全书：什么都懂一点，但未必在某一领域精通。
2. 调用大模型，本质上就是通过 API 向模型服务发起请求并获取结果。
3. AI 应用目前的主流形态包括三类：生成类、知识检索类、自主行动类。
   - 详解：[[AI 应用主流形态（详解）]]

4. 【了解】过拟合：模型把训练数据“记住”得太死，导致对新数据的泛化能力变差。
   - 详解：[[过拟合（详解）]]

5. 【了解】反向传播：用链式法则把误差从输出层逐层传回，高效计算各层参数的梯度，用于更新模型参数。
   - 详解：[[反向传播（详解）]]

6. 【了解】梯度下降：沿着损失函数梯度的反方向（最陡下降方向）迭代更新参数，从而逐步减小损失。
   - 详解：[[梯度下降（详解）]]
